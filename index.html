EXPERIENCIA PRÁCTICA

Mis proyectos

Proyectos destacados con arquitectura Full Stack, bases de datos en la nube y despliegue real.

01

Misha la Gata Viral

Aplicación web completa concebida como ejercicio práctico y escalada a un entorno de producción real. Integra una tienda virtual interactiva con carrito de compras, sistema de autenticación de usuarios por tokens (JWT) y persistencia de pedidos.

Arquitectura Full Stack implementada: El frontend estático se aloja en GitHub Pages, el servidor de API REST con Node.js y Express corre en Render, y los datos se gestionan de forma segura en la nube mediante una base de datos SQLite en Turso, garantizando resiliencia frente a los reinicios del servidor en la nube.

HTML5 / CSS3 JavaScript (DOM) Node.js & Express Turso / SQLite JWT Auth Render

02

EcoKit Universitario

Proyecto universitario enfocado en la sostenibilidad: una propuesta web para transformar el campus con un kit ecológico (botella reutilizable, bolsa, cubiertos y guía de reciclaje) que invita a cuidar el medio ambiente. Incluye un diagnóstico socioambiental con datos y barras animadas, una calculadora de impacto, galería del kit con zoom y un formulario de registro de interesados.

Arquitectura Full Stack implementada: el frontend con navegación por secciones a pantalla completa y scroll continuo, el servidor de API REST con Node.js y Express corre en Render, y los correos registrados se almacenan de forma persistente en la nube mediante una base de datos SQLite en Turso.

HTML5 / CSS3 JavaScript (DOM) Diseño responsive Node.js & Express Turso / SQLite Render
Ver repositorio en GitHub →
03

AgendaAirBNB — Sistema de Reservas

Sistema integral de gestión de reservas hoteleras desarrollado en Java. Permite administrar el registro de huéspedes, el control de disponibilidad de habitaciones y el seguimiento de estadías, ofreciendo tanto una interfaz gráfica intuitiva en Java Swing como una versión operativa por consola.

Arquitectura y persistencia: Construido bajo principios de Programación Orientada a Objetos en Apache NetBeans, con almacenamiento relacional persistente en MySQL y control de versiones gestionado con Git y GitHub.

Java Java Swing MySQL POO NetBeans Git & GitHub
Ver repositorio en GitHub →
04

SistemaEsSalud — Gestión Médica

Aplicación de escritorio orientada a la administración hospitalaria, diseñada para gestionar el registro de pacientes, la programación de citas médicas y el historial de consultas de manera ágil y organizada mediante una interfaz gráfica en Java Swing.

Arquitectura y persistencia: Desarrollado en Apache NetBeans bajo una estructura modular por capas que separa la lógica de negocio de la presentación, utilizando archivos JSON para la serialización y persistencia local de los registros.

Java Java Swing Arquitectura por capas JSON NetBeans Git & GitHub
