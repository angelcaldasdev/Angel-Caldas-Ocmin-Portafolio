Mis proyectos

Proyecto destacado, arquitectura Full Stack y tienda virtual.

01

Misha la Gata Viral

Aplicación web completa concebida como ejercicio práctico y escalada a un entorno de producción real. Integra una tienda virtual interactiva con carrito de compras, sistema de autenticación de usuarios por tokens (JWT) y persistencia de pedidos.

Arquitectura Full Stack implementada: El frontend estático se aloja en GitHub Pages, el servidor de API REST con Node.js y Express corre en Render, y los datos se gestionan de forma segura en la nube mediante una base de datos SQLite en Turso, garantizando resiliencia frente a los reinicios del servidor en la nube.

HTML5 / CSS3 JavaScript (DOM) Node.js & Express Turso / SQLite JWT Auth Render
