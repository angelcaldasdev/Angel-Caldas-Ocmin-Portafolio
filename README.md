## ▶️ Cómo ejecutar el proyecto

### Requisitos
- Visual Studio Code.
- Navegador web.
- Extensión Live Server.

### Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/angelcaldasdev/Angel-Caldas-Ocmin-Portafolio.git
```

2. Ingresar a la carpeta:

```bash
cd Angel-Caldas-Ocmin-Portafolio
```

3. Abrir el proyecto en Visual Studio Code.

4. Ejecutar el archivo `index.html` utilizando la extensión **Live Server**.
